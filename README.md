# FitOS  🏃‍♂️

### Simple Fitness Tracker – Pure HTML, CSS & JavaScript

Log your daily steps and calories burned – everything stays in your browser.

</div>


<br>

## ✨ Features

- Add daily steps & calories  
- Real-time table of your entries  
- Data saved forever in browser (`localStorage`)  
- Delete any entry with one click  
- Clean, responsive design (mobile + desktop)  
- No backend, no login, no installation  
- Zero dependencies – only **HTML + CSS + Vanilla JavaScript**

Perfect for:
- Beginners learning DOM manipulation & localStorage
- Quick personal tracker
- Base to later add charts, goals, export, etc.
<br>

## 🛠️ Technologies

| Technology       | Usage                              |
|------------------|------------------------------------|
| HTML5            | Structure & Semantics             |
| CSS3             | Layout, Flexbox, Responsive design |
| Vanilla JavaScript | Logic, DOM, localStorage         |

**No frameworks · No npm · No build step**
